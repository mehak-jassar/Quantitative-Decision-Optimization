# Quantitative Decision & Optimization

Quantitative decision-making and optimization models developed using Excel Solver and @RISK.

## Project Overview

This repository contains quantitative models demonstrating optimization and risk-based decision analysis using spreadsheet-based methods.

## Optimization Models

### Sitting Sales Representatives
An Excel Solver model for determining the number of sales representatives and district openings required to meet call requirements while minimizing annual cost.

### Wild Turkey
An Excel Solver optimization model for determining turkey procurement and cutlet production decisions to maximize profit under production and demand constraints.

## Risk Simulation

### Heating Element
An @RISK simulation model evaluating preventive replacement policies for heating elements under uncertain demand, failure, and operating conditions.

The simulation compares replacement policies based on profitability and queue-related outcomes.

## Tools & Methods

- Microsoft Excel
- Excel Solver
- @RISK
- Linear and integer optimization
- Cost minimization
- Profit maximization
- Monte Carlo simulation
- Decision analysis
- Risk modelling
